# 電話の確かめの道具（持ち主 CL-3。docs/PHONE.md 3章）

管理者の PC で、電話をつなぐ部分を確かめる道具。**本番のプログラムではない**ので、本番の置き場（`app/src`）の外に置く
（本番の中で電話をかけてよいのは発信の出口 `core/dial_exit.py` の1か所だけ＝見張り I-1。確かめの道具は、確かめのために直接かける）。

| 道具 | 確かめること |
|---|---|
| `probe_audio.py` | 声が録れる・届く・戻らない（R-2〜R-4） |
| `probe_screen.py` | Rakuten Link の画面の部品の名前を読む（決まった言葉と部品の名前だけを写す） |
| `probe_dial.py` | 発信・通話の状態・切る（R-5・R-6） |
| `probe_sms.py` | ショートメールを1通送る（R-9） |
| `probe_call.py` | 本物の電話の部品で、1本の電話を通しで動かす |

かける・送る相手は、管理者の手元の電話かご家族の電話だけ。番号は結果に残さない（下4けただけ）。
