### 2-1. 【CL-2 へ】会話に渡す項目の形（仮・版 0.1）
⚠️ **仮**。名乗りを録音で流すか（DESIGN.md 6-13）が決まると、項目が増える。変わる前提で作ってください。変えるときは、ここに版を上げて書きます。
試作のコード：`phase0/instruction.py` の `Business`、`phase0/flowctl.py` の `Question`（CL-2 は、本番のデータの形を作ったら、ここへ「できた」と書いてください。CL-1 の会話のコードを、そちらを読む形に切り替えます）。

| まとまり | 項目 | 中身 |
|---|---|---|
| 名乗り | 自社名 | 表記と読み（Intent.md 6-8） |
| | 担当者名 | 表記と読み |
| | 用件の一文 | 例：「ご予約の確認でお電話いたしました。」（空でもよい） |
| 質問（並び順つき） | 質問ID | 業務の中で一意。例：Q1 |
| | 質問の文 | 例：「ご希望の日時をお聞かせください。」 |
| | 型 | 型の一覧（DESIGN.md 4-4・2章 Q19）の名前だけ。**確かめる型**＝日付・時刻・日時・数・金額・名前・電話番号・メール・住所／**確かめない型**＝はい／いいえ・決まった選択肢・自由な意見。一覧に無い型は取込で落とす |
| | 必須か | 必須の項目だけ聞き返す（DESIGN.md 6-11） |
| | 選択肢 | **依頼主が書いたまま（日本語）**。例：「はい」「いいえ」、値を聞く質問なら「答えた」。⛔ システムが足す「わからない」「答えたくない」と同じ名前は使えない（取込で止める） |
| 言ってはいけないこと | 文の一覧 | 例：「値引き・割引・無料にすることを、約束したり、できると言ったりすること」 |
| 忙しいと言われたとき | 一言 | 空なら丁寧に終える（既定）。文があれば1回だけそれで聞く（Intent.md 9-4） |

### 2-2. 【CL-2・CL-3 へ】会話から返すもの（仮・版 0.1）
| もの | 中身 |
|---|---|
| 項目ごとの状態 | 状態の名前は DESIGN.md 4-4 の図のものだけ（empty・heard・unclear・checking・confirmed・accepted・unresolved・refused）。値・選んだ選択肢・聞き返し／念のための確認／訂正の回数・状態の移り変わりの履歴（理由つき） |
| 取れたか | 「取れた」＝ confirmed か accepted（DESIGN.md 4-4 の定義だけを使う） |
| 急いでいて終えたか | 相手が急いでいる・通話を断られた、で終えたか |
| まだ作っていないもの | 相手の種別（受付・本人・留守電など。DESIGN.md 4-3）の報告、「もうかけないで」の報告（6-2）。⏳ CL-1 がフェーズ1で作る |

### 2-3. 【CL-3 へ】依頼主へ渡す書き方（DESIGN.md 7-1b。ユーザー確定）
- 取れた項目：確かめる型・自由な意見は値、選択肢の型は選んだ選択肢（相手の言葉ではない）。
- 取れなかった項目：依頼主の指定が無ければ「-」（わからない・聞けなかった）、「✕」（答えたくない）。
- ⚠️ いまは CL-1 の試作（`phase0/flowctl.py` の `export`）に同じ決まりがある。本番の処理は CL-3 の持ち場（`docs/TEAM_PLAN.md` 1-1 の Q20）。CL-3 が作ったら、ここに書く試作を消します。
