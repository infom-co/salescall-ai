# 分担（2026-10-13 ユーザー決定）— CL-1・CL-2・CL-3

クラウドで動くAIを3つにして、SalesCall AI の開発を分ける。この文書は、3つの担当の**全員**が読む。
各担当への引き継ぎ：`docs/HANDOFF_CL-2.md`・`docs/HANDOFF_CL-3.md`（CL-1 は、これまでの担当がそのまま続ける）。

| 名前 | ひとことで | Gemini のキー |
|---|---|---|
| **CL-1 SalesCall AI** | 会話の担当（会話AI・流れの制御・決まった言い方・通話後の検証・フェーズ0の確かめ） | **使うのは CL-1 だけ** |
| **CL-2 SalesCall AI** | 業務の土台の担当（データの形・業務設定と取込・発信対象・安全の門・判定・保存） | 使わない |
| **CL-3 SalesCall AI** | 画面と出力の担当（依頼者別ダッシュボード・検証モードの画面・結果の出力と書き戻し） | 使わない |
