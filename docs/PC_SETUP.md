# 本番の PC の準備（PC の部品を動かす）

> 持ち主：CL-2。設計は `docs/DESIGN.md` 5-5（サーバーと PC の分け方）・5-4（中央の見守り役）・3-10（控え）。
> この手順は、その PC を使う契約者（いまは管理者のユーザー自身）が PC の前で行います。**鍵やパスワードの文字は、チャットに貼らないでください。**
> 2026-10-21 から、契約者の PC には「電話をつなぐ部分（PC の部品）」だけを置きます（ユーザー承認：プログラムを読み取られないように）。電話をかける判断・会話・結果のまとめ・費用の見張り・控えの書き出しは、すべてサーバー（中央の見守り役）がします。PC はデータベースにつながず、サーバーにだけつなぎます。

## この手順でできるようになること
- PC にログインすると、PC の部品が自動で動き出し、サーバーにつなぎます。
- PC の部品は、次のことをします。
  - サーバーに「動いている」と知らせる（途切れたら、サーバーが契約者と管理者に知らせます）
  - サーバーに頼まれたときだけ、電話をかける・切る（電話接続の部品ができてから）
  - 通話の声を、サーバーとスマホのあいだで受け渡す
  - 控え（バックアップ）を、PC につないだハードディスクに暗号化して書き、読み戻して確かめる（中身はサーバーが送ります。鍵は PC の中だけ）
  - 本番の PC の上の緊急停止
- 控えは、PC につないだハードディスク（例：E ドライブ）の `E:\salescall-backup\` に置かれます（依頼者ごとのフォルダ）。データベース全体の控え（`E:\salescall-backup\system\`）は、サーバーの設定で決めた管理者の PC にだけ置かれます。

## 1. 用意するもの
1. Windows の PC（スリープしない・自動で更新の再起動をしない設定にします。計画書 14-4）
   - **時刻を自動で合わせる**設定にします（「設定」→「時刻と言語」→「日付と時刻」で「時刻を自動的に設定する」をオン）。控えのファイルの名前の日時と、古い控えの片付けに使います（計画書 14-4）。
   - Windows 11 を使います。Windows 10 を使い続けるときは、延長セキュリティ更新（ESU）に登録し、登録したことと終わる日を記録に残します（計画書 14-3。終わる日は Microsoft の公式のページで確かめます）。
2. Python 3.13 と、このシステムのプログラム。プログラムのフォルダ（リポジトリ）で、次の2つを1回だけ流します（`app/README.md` と同じ）。⏳ インストーラーができたら、入れるだけで済むようにします。
   - `python -m venv app\.venv`（このシステム専用の Python の置き場を作る）
   - `app\.venv\Scripts\pip install -e app`（このシステムと、使う部品を入れる）
3. 控え用のハードディスク（例：E ドライブ）
4. Proton Pass に作った「控えの鍵の文字」（20文字以上。英数字や記号が混ざった方。単語を並べた方は使わない）。契約者ごとに、自分の Proton Pass に作ります（その契約者の控えは、その文字でしか開けません。サーバーは、この文字を持ちません）

## 1b. PC そのものを守る（計画書 14-1）
PC は自動でログインし、控えの鍵の文字も PC の中（環境変数）に入っています。PC を持ち出されると、中の鍵で控えを開けられてしまうので、PC そのものを守ります。
1. **置き場所**：関係のない人が触れない場所（鍵のかかる部屋など）に置きます。
2. **ディスクの暗号化**：「設定」→「プライバシーとセキュリティ」→「デバイスの暗号化」（Windows の版によっては「BitLocker ドライブ暗号化」）をオンにします。回復キーは、控えの鍵と同じく Proton Pass に置きます（チャットに貼らない）。
3. **画面のロック**：⏳ 画面をロックすると、Rakuten Link の画面の操作が動かなくなる恐れがあります。電話接続の部品ができたら確かめて、ここに書きます（それまでは、1 の置き場所で守ります）。

## 2. ハードディスクの準備
1. ハードディスクの一番上（例：`E:\`）に、`salescall-backup-drive.txt` という名前のファイルを作ります（中身は何でも構いません）。
   - このファイルが無いと、PC の部品は「ハードディスクがつながっていない」とみなし、控えを書きません（サーバーが「ハードディスクをつないでください」と知らせます）。
   - こうしておくと、ハードディスクを外したときに、PC の中へ間違って控えを置くことがありません。

## 3. 設定を入れる（Windows の環境変数）
1. スタートメニューで「環境変数」と入力し、「環境変数を編集」を開きます。
2. 上の欄（ユーザー環境変数）で「新規」を押し、下の名前と値を1つずつ入れます。

| 名前 | 入れるもの | 要るとき |
|---|---|---|
| `SALESCALL_SERVER_URL` | SalesCall AI のサーバーの場所（`https://` で始まるもの。決まったら知らせます） | いつも |
| `SALESCALL_HUB_URL` | サーバーのつなぎ口の場所（ふつうは入れません。入れなければ、上の場所の `/link` につなぎます。`wss://` で始まるものだけ） | 場所を変えるとき |
| `SALESCALL_LINES` | この PC につないだ回線の ID（2本以上はカンマで区切ります。サーバーが、その契約者の回線かを確かめ直します） | 電話をかけるとき |
| `SALESCALL_PHONE` | 電話の部品の名前（電話接続の部品ができたら、その担当が知らせます） | 電話をかけるとき |
| `SALESCALL_UPDATER` | プログラムを自動で入れ替える部品の名前（インストーラーが入れます。まだありません。入っていなければ、更新があるときは「プログラムを更新してください」と知らせます） | 自動の更新をするとき |
| `SALESCALL_BACKUP_DRIVE` | 控え用のハードディスクの一番上（例：`E:\`） | いつも（その契約者の控え） |
| `SALESCALL_BACKUP_KEY` | Proton Pass の控えの鍵の文字（**Proton Pass からコピーして貼り付けます。手で打たない**） | いつも（その契約者の控え） |

- PC の部品は、この表の名前の値だけを読みます。ほかの値は読みません。値は画面・記録に出ません。
- **データベースの接続の文字・会話AIと判定のAIのキーは、契約者の PC に入れません**（PC はデータベースにつながず、会話もサーバーで動きます）。キーは、中央の見守り役が動く所（サーバー。サーバーができるまでは管理者の PC＝`app/README.md`）に置きます。⏳ 契約者のキーをサーバーで預かる形は、CL-1 と決めます（DESIGN.md 5-5 の「このあと測って決めること」）。

## 4. 確かめる
PowerShell を開き、プログラムのフォルダ（`app`）で次を実行します。この手順書の `python` は、1章で作った置き場の Python（`.venv\Scripts\python`）のことです（先に `.venv\Scripts\Activate.ps1` を流すと、`python` だけで動きます）。

1. 設定が入っているか（値は出ません）
   ```
   python -m salescall.agent status
   ```
   - 「入っていません」が出た名前を、3 で入れ直します。最後の行に、この PC のログインが済んでいるかが出ます。
2. 控えの鍵が、Proton Pass の文字と同じか
   ```
   python -m salescall.agent check-key
   ```
   - 「貼り付けて Enter」と出たら、Proton Pass の文字を貼り付けて Enter を押します（画面には出ません）。
   - 「一致しました」と出れば大丈夫です。「違います」と出たら、3 の `SALESCALL_BACKUP_KEY` を、Proton Pass からもう一度コピーして貼り直します。

## 4b. PC のログイン
- **命令を打つ必要はありません。** PC の部品が初めて動いたとき（下の 5 で、ログオンのときに自動で動きます）、まだログインしていなければ、ブラウザで SalesCall AI のログインのページが自動で開きます。
- ふだんどおりにログインします（ID とパスワード、または Google のアカウント。2段階認証を設定していれば、その確かめも。パスキーも使えます）。ページに確かめのコードが出たら、PC の画面のコードと同じかを確かめて「この PC を使う」を押します。
- それで終わりです。PC の部品は、そのまま動き出します。パスワードを PC に入れる必要はありません（この PC の通行証が、自動で PC の中にしまわれます。その Windows の利用者だけが開ける形で、画面には出ません）。
- ログインしないまま閉じたときは、しばらくしてから、もう一度ログインのページが開きます。
- PC を替えたときは、新しい PC で PC の部品を動かすだけです。古い PC は、画面の「この PC のログインを外す」で外せます（外した PC は、次の合図でサーバーに断られ、ログインのページが開きます）。
- ⏳ ログインのページは、画面ができたら使えます。**それまで（サーバーができるまで、管理者の PC で中央の見守り役も一緒に動かす間）は、何もしなくてかまいません**：同じ PC の中央の見守り役が、この PC の通行証を自分で入れます（`app/README.md`「中央の見守り役を動かす」）。管理者が手で直すときは `python -m salescall.agent login`（しまった通行証を消すのは `logout`）。

## 5. ログインのときに自動で動かす
1. スタートメニューで「タスク スケジューラ」を開き、「タスクの作成」を押します。
2. 「トリガー」で「ログオン時」を選びます。
3. 「操作」で「プログラムの開始」を選び、次のように入れます。
   - プログラム：1章で作った置き場の Python（`<リポジトリ>\app\.venv\Scripts\python.exe`。ただの `python` では、このシステムの部品が入っていない Python が動きます）
   - 引数：`-m salescall.agent run`
   - 開始：プログラムのフォルダ（`app`）
4. PC が自動でログインするように設定します（停電のあとも、自分で動き出すようにするため）。
5. PC の部品を動かす Windows の利用者は、1台の PC で1人だけにします（同じ PC で2つ動かそうとしても、2つ目は「もう動いています」で動きません。同じスマホで二重にかけないための守りです）。
- ログインのときにネットがまだつながっていなくても、PC の部品は止まらずに待ち、つながったら動き出します（つながりが切れたときも、間をあけてつなぎ直します）。
- サーバーとのつながりが通話の途中で切れたら、電話の部品が、おわびの録音を流して切ります（お客様を無言で待たせません）。

## 6. 止めるとき
- ふだん：PC の部品の画面で Ctrl+C を押します（通話の途中なら、おわびの録音を流して切ります）。電話をかけるのを止めるだけなら、画面の停止を使います。
- 緊急のとき（画面が開けない・ネットが切れているときも）：
  ```
  python -m salescall.agent emergency stop "止める理由"
  ```
  - この PC は、すぐかけなくなります（PC の中の印。ネットが切れていても必ず効きます）。
  - サーバーにつながっていれば（つながったら）、その契約者の緊急停止として記録されます（画面にも出て、その契約者のほかの PC も止まります）。
  - 状態を見る：`python -m salescall.agent emergency status`
  - 解くとき：`python -m salescall.agent emergency release "解く理由"`（サーバーで解けてから印が消えます。届かないうちは止めたままです）。画面から解いてもかまいません（そのときは、サーバーが PC の印を消します）。
  - すべての契約者の電話を止めるのは、管理者が画面からします。

## 7. うまく動かないとき
- PC の部品は、自分では止まりません。うまくいかないことがあると、サーバーが知らせに出します。
  - PC からの合図が途切れた → その契約者と管理者へ「PC（電話をつなぐ部品）からの動いている合図が途切れました」。PC の電源・ネット・PC の部品が動いているかを確かめてください。
  - ハードディスクが外れている → その PC の契約者へ「ハードディスクをつないでください」（データベース全体の控えなら、管理者へ）
  - 鍵が入っていない → 同じく「控えの鍵を入れてください」
  - PC のプログラムが古い → その契約者と管理者へ「プログラムを更新してください」（自動で入れ替える部品があれば「自動で入れ替えます」）。更新が済むまで、その PC からは電話をかけません。
  - プログラムの誤り → 担当（CL-2 など）に修正依頼が出て、管理者（と、その契約者）に知らせが出ます。管理者は、直った中身を確かめて承認するだけです。
  - 「控えが1日以上取れていません」 → その契約者の PC がつながっていないか、控えを取る設定（ハードディスクの場所 `SALESCALL_BACKUP_DRIVE`・鍵 `SALESCALL_BACKUP_KEY`）が入っていないか、間違っています。3章の手順で入れ直してください。
