# 本番の PC の準備（見守り役を動かす）

> 持ち主：CL-2。設計は `docs/DESIGN.md` 5-4（見守り役）・3-10（控え）。
> この手順は、管理者（ユーザー）が PC の前で行います。**鍵やパスワードの文字は、チャットに貼らないでください。**

## この手順でできるようになること
- PC にログインすると、見守り役が自動で動き出します。
- 見守り役は、次のことを決まった間隔で行います。
  - 電話をかける（回線の部品と会話の部品がそろってから）
  - 通話の結果をまとめる
  - 費用の見張り
  - 止まった仕組みの確かめ
  - 祝日の暦の取り込み
  - 控え（バックアップ）
- 控えは、PC につないだハードディスク（例：E ドライブ）の `E:\salescall-backup\` に置かれます。

## 1. 用意するもの
1. Windows の PC（スリープしない・自動で更新の再起動をしない設定にします。計画書 14-4）
2. Python 3.13 と、このシステムのプログラム
3. 控え用のハードディスク（例：E ドライブ）
4. Proton Pass に作った「控えの鍵の文字」（20文字以上。英数字や記号が混ざった方。単語を並べた方は使わない）

## 2. ハードディスクの準備
1. ハードディスクの一番上（例：`E:\`）に、`salescall-backup-drive.txt` という名前のファイルを作ります（中身は何でも構いません）。
   - このファイルが無いと、見守り役は「ハードディスクがつながっていない」とみなし、控えを置きません。
   - こうしておくと、ハードディスクを外したときに、PC の中へ間違って控えを置くことがありません。

## 3. 設定を入れる（Windows の環境変数）
1. スタートメニューで「環境変数」と入力し、「環境変数を編集」を開きます。
2. 上の欄（ユーザー環境変数）で「新規」を押し、下の名前と値を1つずつ入れます。

| 名前 | 入れるもの | 要るとき |
|---|---|---|
| `SALESCALL_DSN` | データベースへの接続の文字（Fly.io にデータベースを置くときに決まります） | いつも |
| `SALESCALL_TENANT_ID` | 契約者の ID（画面で分かります） | いつも |
| `SALESCALL_LINES` | この PC につないだ回線の ID（2本以上はカンマで区切ります） | 電話をかけるとき |
| `SALESCALL_LINE_DRIVER` | 回線の部品の名前（電話接続の部品ができたら、その担当が知らせます） | 電話をかけるとき |
| `SALESCALL_CALL_RUNNER` | 通話を進める部品の名前（会話の部品ができたら、CL-1 が知らせます） | 電話をかけるとき |
| `SALESCALL_VERIFIER` | 通話後の確かめの部品の名前（CL-1 が知らせます） | 確かめをこの PC でするとき |
| `SALESCALL_PROBER` | 止まった仕組みを確かめる部品の名前（CL-1・電話接続の担当が知らせます） | 確かめをこの PC でするとき |
| `SALESCALL_SYSTEM_JOBS` | `1`（管理者の PC だけ） | 管理者の PC |
| `SALESCALL_OWNER_DSN` | データベースへの接続の文字（控えを取る役） | 控えを取る PC |
| `SALESCALL_RESTORE_DSN` | 「戻せるか」を確かめる、空のデータベースへの接続の文字（**本番とは別のもの**） | 控えを取る PC |
| `SALESCALL_BACKUP_DRIVE` | 控え用のハードディスクの一番上（例：`E:\`） | 控えを取る PC |
| `SALESCALL_BACKUP_KEY` | Proton Pass の控えの鍵の文字（**Proton Pass からコピーして貼り付けます。手で打たない**） | 控えを取る PC |

- 見守り役は、この表の名前の値だけを読みます。会話AIのキーなど、ほかの値は読みません。
- 「戻せるか」の確かめ用のデータベースに本番と同じものを入れてしまっても、見守り役は気づいて止めます（本番のデータを消しません）。

## 4. 確かめる
PowerShell を開き、プログラムのフォルダ（`app`）で次を実行します。

1. 設定が入っているか（値は出ません）
   ```
   python -m salescall.supervisor status
   ```
   - 「入っていません」が出た名前を、3 で入れ直します。
2. 控えの鍵が、Proton Pass の文字と同じか
   ```
   python -m salescall.supervisor check-key
   ```
   - 「貼り付けて Enter」と出たら、Proton Pass の文字を貼り付けて Enter を押します（画面には出ません）。
   - 「一致しました」と出れば大丈夫です。「違います」と出たら、3 の `SALESCALL_BACKUP_KEY` を、Proton Pass からもう一度コピーして貼り直します。

## 5. ログインのときに自動で動かす
1. スタートメニューで「タスク スケジューラ」を開き、「タスクの作成」を押します。
2. 「トリガー」で「ログオン時」を選びます。
3. 「操作」で「プログラムの開始」を選び、次のように入れます。
   - プログラム：`python`
   - 引数：`-m salescall.supervisor run`
   - 開始：プログラムのフォルダ（`app`）
4. PC が自動でログインするように設定します（停電のあとも、自分で動き出すようにするため）。

## 6. 止めるとき
- ふだん：見守り役の画面で Ctrl+C を押します。いまの通話を最後まで終えてから止まります。
- 緊急のとき（画面が開けない・ネットが切れているときも）：
  ```
  python -m salescall.core.emergency stop "止める理由"
  ```

## 7. うまく動かないとき
- 見守り役は、自分では止まりません。うまくいかないことがあると、管理者への知らせに出ます。
  - ハードディスクが外れている → 「ハードディスクをつないでください」
  - 鍵が入っていない → 「控えの鍵を入れてください」
  - プログラムの誤り → 担当（CL-2 など）に修正依頼が出ます。管理者は、直った中身を確かめて承認するだけです。
