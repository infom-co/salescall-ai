# 本番の PC の準備（見守り役を動かす）

> 持ち主：CL-2。設計は `docs/DESIGN.md` 5-4（見守り役）・3-10（控え）。
> この手順は、その PC を使う契約者（いまは管理者のユーザー自身）が PC の前で行います。**鍵やパスワードの文字は、チャットに貼らないでください。**
> 1台の PC は、1人の契約者の分だけを動かします（その契約者の回線・費用の見張り・控え）。管理者の PC だけは、すべての契約者に共通の仕事（祝日の暦・データベース全体の控え）もします。

## この手順でできるようになること
- PC にログインすると、見守り役が自動で動き出します。
- 見守り役は、次のことを決まった間隔で行います。
  - 電話をかける（回線の部品と会話の部品がそろってから）
  - 通話の結果をまとめる
  - 費用の見張り（その契約者の分）
  - 止まった仕組みの確かめ
  - 祝日の暦の取り込み
  - 控え（バックアップ。その契約者の依頼者の分）
- 控えは、PC につないだハードディスク（例：E ドライブ）の `E:\salescall-backup\` に置かれます（依頼者ごとのフォルダ）。管理者の PC には、データベース全体の控え（`E:\salescall-backup\system\`）も置かれます。

## 1. 用意するもの
1. Windows の PC（スリープしない・自動で更新の再起動をしない設定にします。計画書 14-4）
2. Python 3.13 と、このシステムのプログラム
3. 控え用のハードディスク（例：E ドライブ）
4. Proton Pass に作った「控えの鍵の文字」（20文字以上。英数字や記号が混ざった方。単語を並べた方は使わない）。契約者ごとに、自分の Proton Pass に作ります（その契約者の控えは、その文字でしか開けません）

## 2. ハードディスクの準備
1. ハードディスクの一番上（例：`E:\`）に、`salescall-backup-drive.txt` という名前のファイルを作ります（中身は何でも構いません）。
   - このファイルが無いと、見守り役は「ハードディスクがつながっていない」とみなし、控えを置きません。
   - こうしておくと、ハードディスクを外したときに、PC の中へ間違って控えを置くことがありません。

## 3. 設定を入れる（Windows の環境変数）
1. スタートメニューで「環境変数」と入力し、「環境変数を編集」を開きます。
2. 上の欄（ユーザー環境変数）で「新規」を押し、下の名前と値を1つずつ入れます。

| 名前 | 入れるもの | 要るとき |
|---|---|---|
| `SALESCALL_DSN` | データベースへの接続の文字。**管理者の PC だけ**（システムの接続の文字）。契約者の PC は入れません（下の「PC のログイン」で、鍵が自動で入ります） | 管理者の PC |
| `SALESCALL_TENANT_ID` | 契約者の ID。**管理者の PC だけ**（契約者の PC は、ログインした契約者になります） | 管理者の PC |
| `SALESCALL_SERVER_URL` | SalesCall AI のサーバーの場所（`https://` で始まるもの。決まったら知らせます） | 契約者の PC |
| `SALESCALL_LINES` | この PC につないだ回線の ID（2本以上はカンマで区切ります） | 電話をかけるとき |
| `SALESCALL_LINE_DRIVER` | 回線の部品の名前（電話接続の部品ができたら、その担当が知らせます） | 電話をかけるとき |
| `SALESCALL_CALL_RUNNER` | 通話を進める部品の名前（会話の部品ができたら、CL-1 が知らせます） | 電話をかけるとき |
| `SALESCALL_VERIFIER` | 通話後の確かめの部品の名前（CL-1 が知らせます） | 確かめをこの PC でするとき |
| `SALESCALL_PROBER` | 止まった仕組みを確かめる部品の名前（CL-1・電話接続の担当が知らせます） | 確かめをこの PC でするとき |
| `SALESCALL_BACKUP_DRIVE` | 控え用のハードディスクの一番上（例：`E:\`） | いつも（その契約者の控え） |
| `SALESCALL_BACKUP_KEY` | Proton Pass の控えの鍵の文字（**Proton Pass からコピーして貼り付けます。手で打たない**） | いつも（その契約者の控え） |
| `SALESCALL_SYSTEM_JOBS` | `1`（管理者の PC だけ） | 管理者の PC |
| `SALESCALL_OWNER_DSN` | データベースへの接続の文字（データベース全体の控えを取る役） | 管理者の PC |
| `SALESCALL_RESTORE_DSN` | 「戻せるか」を確かめる、空のデータベースへの接続の文字（**本番とは別のもの**） | 管理者の PC |

- 見守り役は、この表の名前の値だけを読みます。会話AIのキーなど、ほかの値は読みません。
- **会話AIと判定のAIのキー**は、この表ではなく、キーのファイル（`C:\Users\User\SalesCall\.env`。Intent.md 12-3）に入れます。読むのは会話の部品の1か所だけです（キーを使うのは CL-1 の部品だけ）。値は画面・記録に出ません。
  | 名前 | 入れるもの |
  |---|---|
  | `GEMINI_API_KEY_1`・`GEMINI_API_KEY_2`… | 会話AI（Gemini）のキー（いくつでも。上限に当たったら次のキーで続けます） |
  | `ANTHROPIC_JUDGE_KEY` | 2つ目の判定（Claude Sonnet 5.5）のキー（CL-1 の連絡帳 4-21。判定に使うAIは契約者の設定 `judge.models`） |
- 「戻せるか」の確かめ用のデータベースに本番と同じものを入れてしまっても、見守り役は気づいて止めます（本番のデータを消しません）。

## 4. 確かめる
PowerShell を開き、プログラムのフォルダ（`app`）で次を実行します。

1. 設定が入っているか（値は出ません）
   ```
   python -m salescall.supervisor status
   ```
   - 「入っていません」が出た名前を、3 で入れ直します。
2. 控えの鍵が、Proton Pass の文字と同じか
   ```
   python -m salescall.supervisor check-key
   ```
   - 「貼り付けて Enter」と出たら、Proton Pass の文字を貼り付けて Enter を押します（画面には出ません）。
   - 「一致しました」と出れば大丈夫です。「違います」と出たら、3 の `SALESCALL_BACKUP_KEY` を、Proton Pass からもう一度コピーして貼り直します。

## 4b. PC のログイン（契約者の PC）
- **命令を打つ必要はありません。** 見守り役が初めて動いたとき（下の 5 で、ログオンのときに自動で動きます）、まだログインしていなければ、ブラウザで SalesCall AI のログインのページが自動で開きます。
- ふだんどおりにログインします（ID とパスワード、または Google のアカウント。2段階認証を設定していれば、その確かめも。パスキーも使えます）。ページに確かめのコードが出たら、「この PC を使う」を押します。
- それで終わりです。見守り役は、そのまま動き出します。パスワードや鍵を、PC に入れる必要はありません（PC の鍵は、自動で PC の中にしまわれ、画面には出ません）。
- ログインしないまま閉じたときは、しばらくしてから、もう一度ログインのページが開きます。
- PC を替えたときは、新しい PC で見守り役を動かすだけです。古い PC は、画面の「この PC のログインを外す」で外せます。
- ⏳ ログインのページは、画面ができたら使えます（いまは管理者の PC だけで動かします）。管理者が手で直すときは `python -m salescall.supervisor login`。

## 5. ログインのときに自動で動かす
1. スタートメニューで「タスク スケジューラ」を開き、「タスクの作成」を押します。
2. 「トリガー」で「ログオン時」を選びます。
3. 「操作」で「プログラムの開始」を選び、次のように入れます。
   - プログラム：`python`
   - 引数：`-m salescall.supervisor run`
   - 開始：プログラムのフォルダ（`app`）
4. PC が自動でログインするように設定します（停電のあとも、自分で動き出すようにするため）。
5. 見守り役を動かす Windows の利用者は、1台の PC で1人だけにします（同じ PC で2人が動かそうとしても、2つ目は「もう動いています」で動きません。同じスマホで二重にかけないための守りです）。
- ログインのときにネットがまだつながっていなくても、見守り役は止まらずに待ち、つながったら動き出します。

## 6. 止めるとき
- ふだん：見守り役の画面で Ctrl+C を押します。いまの通話を最後まで終えてから止まります。
- 緊急のとき（画面が開けない・ネットが切れているときも）：
  ```
  python -m salescall.core.emergency stop "止める理由"
  ```

## 7. うまく動かないとき
- 見守り役は、自分では止まりません。うまくいかないことがあると、知らせに出ます。
  - ハードディスクが外れている → その PC の契約者へ「ハードディスクをつないでください」（管理者の PC のデータベース全体の控えなら、管理者へ）
  - 鍵が入っていない → 同じく「控えの鍵を入れてください」
  - プログラムの誤り → 担当（CL-2 など）に修正依頼が出て、管理者（と、その契約者）に知らせが出ます。管理者は、直った中身を確かめて承認するだけです。
