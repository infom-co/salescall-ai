### 1. 背景（判断の材料として読んでください）

- 私たちは、日本で、企業あてに電話をかけてAIが会話する仕組み（営業・予約確認などの電話業務の代行）を作っています。
- 会話には、Google の **Gemini API（Google AI Studio で発行したAPIキーを使う方式）** の **Live API** を使います。
  - 使うモデルのID：**`gemini-3.8-live`**
  - このモデルにAPIで版を問い合わせると、**`3.1-flash-live-03-2026`** という表記が返ってきます（同じモデルの版の表記です）。資料では、どちらの名前で載っているかも確かめてください。
  - 声は **Sadachbia**（男性の候補）と **Leda**（女性の候補）を使い、日本語（`ja-JP`）で話させます。
  - 相手の声（電話の音声）を 16kHz の音声で送り、AIの声を 24kHz の音声で受け取ります。
- 通話の冒頭で、AIであることは告げません。ただし、相手から聞かれたときに人間だと偽ることはしません。
- 相手の声は、通話のあとの確認のために録音して、文字にします。

### 3. 調べること

#### A. 料金（G-10）
1. `gemini-3.8-live` の料金（100万トークンあたり、米ドル）。次の種類ごとに：
   - 入力：文字／音声／画像・動画
   - 出力：文字／音声
   - 「考える」ためのトークン（thinking）は、どの料金で数えられるか
2. Live API の1つのセッションの中で、AIが返事をするたびに、**それまでの会話の全部が入力として数え直されて料金がかかるのか**。公式の説明があれば、その一文を引用してください。
   - 参考（私たちの実測）：4ターンの短い通話で、ターンごとの入力の量が 619 → 830 → 1,075 → 1,221 トークンと増えました。
3. 音声1秒が何トークンとして数えられるか（入力と出力それぞれ）。
   - 参考（私たちの実測）：入力・出力とも、1秒あたり約25トークンでした。
4. 無料枠（free tier）で `gemini-3.8-live` を使えるか。使える場合の条件。
5. **無料枠と有料枠で、送ったデータ（相手の声・会話の中身）が Google の製品の改善に使われるかどうか**の違い。該当する一文を引用してください。
6. 有料枠に切り替えるために必要なこと（請求先の設定など）と、自分のプロジェクトがどちらの枠かを確かめる方法。

#### B. 利用の上限（G-10 の続き）
7. `gemini-3.8-live` の利用の上限を、枠（無料・有料の各段階）ごとに：
   - 1分あたりのリクエスト数（RPM）
   - 1分あたりの入力トークン数（TPM）
   - 1日あたりのリクエスト数（RPD）
   - **同時に開けるセッションの数**
   - 参考（私たちの実測）：同じキーで6本までは同時に通り、8本目で、閉じる番号 1011・文面「You exceeded your current quota, please check your plan and billing details.」で断られました。また、閉じる番号 1008・文面「Your project has been denied access. Please contact support.」が出たことがあり、管理画面では「1分あたりの入力トークン数（TPM）の上限」と表示されていました。
8. 上限に当たったときに返るエラー（番号と文面）の公式の一覧。とくに 1007・1008・1011 の意味。
9. Live API の1回の接続・1回のセッションの長さの上限（音声だけのとき）、切れる前の知らせ（GoAway）、セッションの再開（session resumption）、文脈の圧縮（context window compression）について、公式の記載。
   - 参考（私たちの実測）：無音を流し続けて25分（こちらで決めた上限）まで切れず、切れる前の知らせも来ませんでした。

#### C. 利用規約・禁止されている使い方（G-12）
10. Gemini API の追加の利用規約（Gemini API Additional Terms of Service）と、生成AIの禁止されている使い方の方針（Generative AI Prohibited Use Policy）のうち、次に関係する条文。**該当する一文をそのまま引用**し、URL を付けてください。
    - (a) 電話の自動発信・営業電話（テレマーケティング）・大量の連絡
    - (b) **AIであることを告げないこと**、人間になりすますこと、相手をだますこと。AIが作った音声であることを示す義務があるか
    - (c) 第三者（電話の相手）の声や個人の情報を、送ったり録音したりすること
    - (d) 日本で使えるか（利用できる国・地域の一覧）
    - (e) 年齢の条件、事業での利用の条件
    - (f) 声（Sadachbia・Leda など、用意された声）の使い方に制限があるか
11. 上の (a)〜(f) について、「条文には書いていない（見つからなかった）」ものは、そう書いてください。**法律上よいか悪いかの判断はしないでください**。条文に書いてあることだけを報告してください。
