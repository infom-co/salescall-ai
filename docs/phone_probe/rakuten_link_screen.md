# Rakuten Link デスクトップ版（2.1.0）の画面の部品（2026-11-20・管理者の PC で読んだ。docs/PHONE.md 2-1 の `SCREEN` の材料）

> 管理者の PC で `probe_screen.py` を動かして読んだものから、**画面の部品の形だけ**を写した（通話の履歴・連絡先の名前・番号・ブラウザのタブは写さない）。
> Rakuten Link は Chrome と同じ作りの窓（class `Chrome_WidgetWin_1`）で、部品は UI Automation で読める。

## いつもの窓「Rakuten Link」
| 部品 | 見分け方 | 使い道 |
|---|---|---|
| 「通話」のタブ | Button・AutomationId `calls_tab_btn` | 通話の画面へ |
| 「メッセージ」のタブ | Button・名前「メッセージ」（Id なし） | ショートメール（R-9） |
| 「連絡先」のタブ | Button・Id `contacts_tab_btn` | 使わない |
| ダイヤルパッド | Button・Id `dialpad_btn` | 番号を入れる画面を出す |
| 番号を入れる欄 | Edit・Id `digits-only`（名前「番号を入力」）＝ダイヤルパッドを開いたときだけ出る | 番号を入れる |
| 発信 | Button・Id `dialpad_call_btn` | 発信を押す |
| 数字のボタン | Button・名前「1」〜「9」「*」「#」（0 は名前が無い） | 使わない（欄に入れる） |
| 通話を検索 | Edit・Id `input-search-bar` | 使わない（番号を入れる所ではない） |
| 最近・留守番電話 | ListItem・Id `recent_calls_tab_btn`・`voicemail_tab_btn` | 使わない |
| スマホとの連携の表示 | ⏳ いつもの画面には出ていない（連携が切れたときに出る見込み。切った状態で読む） | 2-6 |

## 通話中に出る別の窓「Rakuten Link Call」
| 部品 | 見分け方 | 使い道 |
|---|---|---|
| 窓そのもの | 窓の名前「Rakuten Link Call」 | **この窓があるあいだは通話中（呼び出し中を含む）**＝`in_call` の材料 |
| 通話の時間 | Document Id `call-ui` の中の Text（例「00:02」） | ⏳ 呼び出し中から数えるか、つながってから数えるかを確かめる（R-6） |
| 通話を終了 | Button・名前「通話を終了」 | `hang_up` |
| ミュート・音声設定・メッセージ・ダイヤルパッド | Button・それぞれの名前 | 使わない（音声設定は、音の出入りの確かめに使えるかも） |

## メッセージ（ショートメール。R-9）
| 部品 | 見分け方 | 使い道 |
|---|---|---|
| 「メッセージ」のタブ | Button・名前「メッセージ」（Id なし） | メッセージの画面へ |
| 新しいメッセージ（＋） | Button・Id `create_new_btn` | 押すと「メッセージ」「グループ」のメニューが出る。メニューの「メッセージ」を選ぶと、宛先を入れる画面（2026-11-20 管理者が教えてくれた。⏳ メニューの部品の形は送信の確かめで読む） |
| 宛先の欄 | Edit・名前「名前または番号を入力」（Id は `mat-chip-list-input-<数>`＝数が変わりうるので名前で見分ける） | 宛先の番号を入れる |
| 送信 | Button・Id `message_send_btn` | 送る |
| 本文の欄 | Text・名前「メッセージを入力」（宛先を入れると出る。入力欄の形では出ないので、押してから貼り付ける） | 本文を入れる |
| 入った宛先 | List・名前「Contact selection」の中の ListItem | 宛先が入ったかの確かめ |
| ショートメールで送られる知らせ | Hyperlink・Id `message_sms_learn_more_btn`（宛先が Rakuten Link を使っていない番号のとき出る見込み） | 使わない（ショートメールになる印） |
| やり取りの一覧 | Group・Id `chat-list-container` の中の MenuItem | 使わない（相手のお名前・文面が入るので、読み取りの道具は写さない） |

## 次に読むもの
- ✅ ダイヤルパッドを押したあとの、番号を入れる欄と発信のボタン（2026-11-20 に読んだ＝上の表）。表は `agent/phones/screen_uia.SCREEN` の1か所に写した。
- スマホとの連携が切れているときの表示（スマホの Wi-Fi を切って読む）。
- 呼び出し中とつながったあとで、通話の時間の表示が変わるか（R-6）。
