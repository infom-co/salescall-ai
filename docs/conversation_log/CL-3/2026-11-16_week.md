## Improvements over the previous design
- **All approval items go into one queue**, sorted urgent first, then deadline, then oldest. Since people only check and approve, each item shows the same thing: what to decide, the evidence, and what happens if no one decides. To add a new kind of approval, you add one row to a table.
- **Clients are picked from a searchable list instead of tabs along the top**, because there may be more than 100 of them. Approval items and stops across all clients are gathered in a single "all" area.
- **Things I had defined twice are now in one place**:
  - My own wording table had duplicated the stop-cause labels; it now reads CL-2's originals instead.
  - The wording table (both the on-screen words and the words sent to clients) lives in one file, and a test fails if any database name is missing a word.
- **Automatic write-back only goes to destinations that "overwrite on the same key"**, so double entries can't happen by construction. The old "a person checks whether it was sent" path is gone.
- **The screens run on the same Fly.io machine as the supervisor**, so they don't eat further into the $5/month limit.

## Defects I found and fixed with the sample screens
- **Client-scoped stops were missing from the "all" stopped-items list.** Those stops are only visible inside that client's transaction, so the list now combines the per-client views.
- **When a stop was out of the user's range, the screen errored instead of answering "not found"** (as it would for a missing item).
- The "resume" button stretched full width because a class name clashed.
- The table header row overlapped the first row.
- Company names wrapped mid-word.

On the customer-list screenshot, rows marked "done: completed" still show "no result yet". That's only because I entered the sample data by hand; real data won't look like this.

- **Cannot be made 100% by construction**: a person misreading the evidence and approving anyway. To reduce this, the evidence and the system's reading are placed right next to the decision.
